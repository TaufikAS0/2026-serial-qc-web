Wiring mengikuti datasheet perangkat

RS232
TX → RX, RX → TX, signal ground bersama. Gunakan adapter RS232, bukan USB–TTL. Nomor pin DB9 bergantung perangkat.

RS485
Polaritas A/B mengikuti datasheet kedua perangkat. Ground, terminasi di ujung bus, dan bias mengikuti topologi. Hanya satu master pada bus.

Kirim payload

Terminal tidak memberikan PASS. Data diterima tetap berupa bytes; HEX menjadi acuan.

Simpan log

Capture tetap berjalan saat tampilan dibekukan. Buffer 1000 event; tampilan 100 event terakhir. Teks ditampilkan UTF-8 dengan replacement, payload asli tersedia dalam HEX.

Tag Modbus RTU

FC01–04 read-only · alamat zero-based · satu request outstanding. 40001 biasanya offset 0 untuk FC03; periksa manual DUT.

Slave / server simulator

Nilai sintetis pada serial nyata diberi label REAL SERIAL + SYNTHETIC VALUES. Respons terkirim tidak membuktikan master mengolahnya.

Profil request / response

Demo hanya untuk simulator yang mendukung PING/PONG atau map Modbus sintetis. Jangan gunakan pada DUT tanpa kontrak protokol yang sesuai.

Riwayat pengujian

200 run terbaru / 64 MB disimpan. CSV UTF-8 BOM untuk Excel; waktu UTC dan zona dicatat. SIMULASI tidak menjadi acceptance hardware.

Layanan background per pengguna

Browser dapat ditutup tanpa mematikan backend. Login Windows menjalankan supervisor melalui HKCU Run; restart crash memakai backoff 2–60 detik.

Start / Open Web saat backend mati: buka Serial Web.cmd. CLI: Serial Web.cmd start|stop|restart|status|open.

Sleep/shutdown menghentikan komunikasi. Setelah wake/restart, port tetap terputus dan run terinterupsi menjadi INCOMPLETE. Command tidak dilanjutkan otomatis. Pengaturan power Windows tidak diubah.
