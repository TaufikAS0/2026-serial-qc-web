# Provenance

Source aplikasi/codec/frontend ditulis untuk repo ini; tidak menyalin firmware/Compact/bundle pihak ketiga. CRC/read mengacu dokumen resmi Modbus di PROFILES.md; PDF tidak dibundel.

Dependensi dari PyPI, terkunci requirements.txt. Upstream licenses: Flask/Werkzeug/Jinja2/MarkupSafe/itsdangerous/Click BSD-3-Clause, Blinker MIT, Waitress ZPL-2.1, pyserial/colorama BSD-3-Clause. Metadata/license tetap tersedia di distribusi wheels/site-packages. pip-audit hanya alat verifikasi, bukan runtime dependency. Audit 14 Oktober 2026: tidak ada vulnerability diketahui pada runtime requirements saat pemeriksaan; bukan jaminan bebas kerentanan.
